# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/bwhittaker69/ca.whittaker.Diagnostics.HttpRequestLogging/security/advisories/new), not public issues. Provide version, impact and synthetic reproduction without real secrets.

There is no guaranteed response time. Reports are assessed against the latest published version. Name-based redaction cannot identify every sensitive value; the application owner must review allowlists and logging access.
